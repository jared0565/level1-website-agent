# Generated Sites Demo Library

Store exported standalone website demos in this folder.

Recommended structure:

```text
generated-sites/
├── index.html
└── example-business/
    └── index.html
```

The app still generates each website as a single self-contained HTML file. Use the preview screen's **Open Site** control to test the generated website as a top-level document, then **Download HTML** and place it in a named subfolder here when you want to commit it as part of the public demo library.
